JudgeIsWin differential experiment — 2026-11-12

Reproduce:
MAHJONG_WIN_EXPERIMENT=1 go test ./src/player -run 'TestJudgeIsWin.*Experiment|TestExperimentOracleKnownHands' -v -count=1 -timeout=10m

Seed: 20261112. Production code was not modified for this experiment.
2,190,387 legal hands; both final=false and final=true were checked
(4,380,774 production calls). Neither false positives nor false negatives
were observed. Both final modes agreed for every sample.

Oracle: independent 34-entry count vector, every possible pair, recursive
triplet AND sequence search, seven pairs (quads count as two pairs), thirteen
orphans. Six explicit known-answer fixtures also check the oracle and target.

Coverage:
- Exhaustive counts 0..4 for nine ranks of one suit, with concealed sizes
  2/5/8/11/14. Honor pungs fill the remaining fixed meld slots.
- 1,000,000 physical-wall random draws with 0..4 fixed honor pungs/kongs.
- 500,000 constructed wins, including mixed suits, honors, exposed sequences,
  pungs and kongs, rejecting any fifth physical copy.
- 500,000 one-tile mutations of constructed wins, still physically legal.
- 5,000 seven-pair hands and 5,000 thirteen-orphan hands.

Findings outside valid-input assumptions:
- Five identical tiles can be accepted as a pair plus a triplet.
- Unknown tile names used as a pair and malformed fixed melds can be accepted.
- CheckIsWaiting demonstrably creates physically impossible candidate hands:
  B1 B1 B1 B1 B2 B2 B2 B3 B3 B3 D D D
  reports B1/B2/B3/B4 as waits, though B1 would require a fifth copy.
  Filtering candidates by concealed + fixed tile counts is needed if waits
  must represent physically possible draws. This is an observed caller issue,
  even if JudgeIsWin intentionally assumes input has already been validated.

Limits: this is not exhaustive over all mixed-suit hands or fixed meld layouts.
The final=true boolean was checked; correctness of scoring tags was not tested.
Boundary tests report behavior rather than enforce a new input contract.
The ordinary go test ./... suite also passed.
